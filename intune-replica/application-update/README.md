# Application Update replica

- `win32-apps/` — aplikasi Win32, detection, install, update, dan uninstall.
- `microsoft-store/` — aplikasi Microsoft Store dan update behavior.
- `m365-apps/` — update channel Microsoft 365 Apps.
- `third-party-apps/` — aplikasi vendor lain beserta metode update.
- `supersedence/` — penggantian aplikasi/versi lama.
- `uninstall/` — rollback atau removal aplikasi.
- `reports/` — status deployment dan kegagalan update.
