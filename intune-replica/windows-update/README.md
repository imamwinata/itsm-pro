# Windows Update replica

- `update-rings/` — konfigurasi deadline, grace period, active hours, restart behavior, dan assignment.
- `quality-updates/` — policy quality/security updates.
- `feature-updates/` — target version deployment, misalnya Windows 11 24H2.
- `expedited-updates/` — deployment percepatan security update tertentu.
- `delivery-optimization/` — bandwidth dan peer delivery.
- `notifications/` — notifikasi dan restart reminder user.
- `reports/` — compliance, deployment state, error, dan rollback evidence.
